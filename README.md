# 🕷️ SPIDER-VERSE // ARCHIVE

An interactive Spider-Verse-inspired dimensional archive built entirely with:

- HTML
- CSS
- JavaScript

No frameworks.
No backend.
No database.

## Features

- Cinematic boot sequence
- Spider-Person database
- Spider personality test
- Spider-Sense reaction game
- Suit archive
- Multiverse generator
- Daily Bugle
- Interactive dimensional map
- Rooftop mini-game
- Classified files
- Hidden terminal
- LocalStorage progress
- Responsive mobile design
